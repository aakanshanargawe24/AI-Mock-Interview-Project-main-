# AI Mock Interview Project

## About the Project
This project is a simple AI-based mock interview system created to help users practice interview questions in a realistic manner. The main goal of this project is to provide a practice environment where users can improve their confidence and interview skills before facing real interviews.



## What This Project Does
- Simulates a basic interview process
- Asks interview questions in an interactive way
- Allows users to practice answering questions
- Helps in understanding how real interviews are structured


## Technologies Used
- Python  
- Flask  
- Basic Artificial Intelligence concepts  
- HTML, CSS, JavaScript  



## How It Works
1. The user starts the interview session  
2. The system asks interview questions  
3. The user responds to the questions  
4. The session continues like a real interview
